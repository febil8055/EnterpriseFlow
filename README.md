# EnterpriseFlow

Enterprise SaaS platform built from scratch using Oracle AI Database, Oracle APEX, PL/SQL, ORDS, and Oracle Cloud Infrastructure.

## Technology Stack

- Oracle AI Database 26ai
- Oracle APEX
- PL/SQL
- ORDS
- REST APIs
- Git
- Docker (later)
- Oracle Cloud Infrastructure (OCI)

## Project Goal

Build a production-quality enterprise application following real-world software engineering practices.
