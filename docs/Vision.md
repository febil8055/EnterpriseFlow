\# EnterpriseFlow



\## Vision



EnterpriseFlow is a cloud-based Enterprise Operations Platform designed to help organizations manage users, projects, workflows, approvals, assets, and reporting through a secure, scalable, and modular application built on Oracle technologies.



\## Goals



\- Build a production-quality Oracle application.

\- Learn enterprise software architecture.

\- Master Oracle Database, PL/SQL, Oracle APEX, REST APIs, OCI, and Git.

\- Create a portfolio project suitable for enterprise Oracle developer interviews.



\## Design Principles



\- Security First

\- API First

\- Modular Architecture

\- Clean PL/SQL

\- Scalable Database Design

\- Enterprise Standards

\# Business Rules



BR-001: An Organization can have multiple Departments.



BR-002: A Department belongs to only one Organization.



BR-003: An Employee belongs to one Department.



BR-004: An Employee may or may not have a User account.



BR-005: A User can have one or more Roles.



BR-006: A Role contains multiple Permissions.



BR-007: A Project belongs to one Organization.



BR-008: A Project contains multiple Tasks.



BR-009: Every important action must be recorded in the Audit Log.



BR-010: Notifications can be sent to one or many Users.
